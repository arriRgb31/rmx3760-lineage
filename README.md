# rmx3760-lineage

Single repository containing device + vendor trees for Realme C53 (RMX3760)
Unisoc UMS9230 (qogirl6 / sharkl6), Android 15 / LineageOS.

Layout:
- `device/realme/rmx3760/`  - device tree (BoardConfig, fstab/init, product makefiles)
- `vendor/realme/rmx3760/`  - vendor blobs tree (proprietary/ to be filled from stock device)
